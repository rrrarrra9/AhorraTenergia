\chapter{Introducción, problema y objetivos}

\section{Introducción}
AhorraTenergia es un proyecto de desarrollo de aplicaciones que propone un prototipo de gestión energética doméstica. Su finalidad es reunir en una misma solución información sobre el consumo eléctrico de una vivienda, la producción de energía solar, el estado de una batería y el precio de la electricidad.

El sistema se plantea como una aplicación que permita \textbf{visualizar estas variables y simular decisiones de gestión energética}. El trabajo combina desarrollo de software, almacenamiento de datos e integración con una placa ESP32, sin intervenir sobre una instalación eléctrica real.

\section{Problema o necesidad detectada}
En una vivienda con instalación fotovoltaica y conexión a la red eléctrica, la energía solar disponible no siempre coincide con los momentos de mayor consumo. Además, el precio de la electricidad puede variar según la hora y una batería introduce otra variable: la energía almacenada.

Consultar estos datos por separado dificulta comprender de dónde procede la energía utilizada y cómo podrían influir el precio, la producción y la batería en las decisiones de consumo. AhorraTenergia aborda esta necesidad mediante una \textbf{visualización conjunta} y escenarios simulados que facilitan el análisis, sin prometer ahorros económicos que todavía no se han medido.

\section{Usuario o cliente objetivo}
La solución está dirigida principalmente a personas que desean conocer y comprender mejor el consumo de su vivienda, especialmente cuando disponen de paneles solares y, de forma opcional, una batería doméstica. También puede utilizarse como demostración educativa de integración entre aplicaciones, datos y electrónica.

\section{Frase de venta y propuesta de valor}
\textbf{Frase de venta:} «Visualiza tu energía y simula decisiones de consumo más informadas».

La propuesta de valor consiste en presentar las principales variables energéticas en una interfaz comprensible y permitir comparar, de forma simulada, diferentes condiciones de consumo, producción solar, precio eléctrico y disponibilidad de batería.

\section{Objetivo general}
Diseñar y desarrollar un \textbf{prototipo demostrativo de gestión energética doméstica} que visualice datos de consumo, generación solar, batería y precio eléctrico, y que permita simular decisiones de gestión mediante una lógica centralizada en el backend.

\section{Objetivos específicos}
\begin{itemize}
  \item Definir la arquitectura y la comunicación entre las interfaces de usuario, el backend, la base de datos y la ESP32.
  \item Generar o recibir datos simulados sobre producción solar, consumo eléctrico y nivel de batería.
  \item Diseñar una API en ASP.NET Core para procesar, consultar y coordinar la información del sistema.
  \item Almacenar las medidas y los resultados simulados en una base de datos PostgreSQL mediante Supabase.
  \item Diseñar un dashboard web con React y una aplicación Android en Java para consultar los datos.
  \item Definir reglas de decisión simuladas basadas en el precio eléctrico y la disponibilidad de energía, y verificar su coherencia mediante pruebas.
\end{itemize}

\section{Alcance inicial y límites del prototipo}
La primera versión se centrará en \textbf{datos simulados} y en demostrar la comunicación entre componentes. La arquitectura prevista emplea React para la web, Java para Android, ASP.NET Core para el backend, Supabase/PostgreSQL para la persistencia y ESP32 programada en C++ para representar la parte electrónica. Son tecnologías previstas para el desarrollo, no funcionalidades que se consideren terminadas en este sprint.

El prototipo \textbf{no conmutará fuentes eléctricas ni controlará equipos domésticos reales}. Tampoco se considerarán verificados el ahorro económico o la precisión de una gestión automática hasta disponer de pruebas y resultados medibles.
