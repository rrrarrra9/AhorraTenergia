# Diseño inicial del dashboard

## Proyecto
AhorraTenergia

## Objetivo
Definir una propuesta visual inicial para la interfaz web que permita consultar información energética de una vivienda con placas solares.

## Boceto
El archivo `dashboard-inicial.png` contiene la propuesta visual de la pantalla principal del dashboard.

## Elementos previstos
- Producción de energía solar.
- Consumo eléctrico de la vivienda.
- Estado de la batería.
- Precio de la electricidad.
- Visualización gráfica de producción y consumo.
- Modos de funcionamiento automático y manual.

## Estado
Diseño inicial propuesto. Las métricas y funcionalidades representadas son ilustrativas y no implican que exista una conexión funcional con la placa ESP32.
